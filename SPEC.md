## Functional contract
- Toolbar opens workbench to user-invoked extract active tab: activeTab/scripting, no all-sites host access or background scraping. Extract rendered HTML tables, ARIA tables/grids, or list items; list selector is explicit user input, no arbitrary code. Do not read inputs, credentials, contact directories or hidden content. No crawling, login bypass, pagination automation or personal contact collection. Block unsupported scheme/store pages.
- Use visible DOM, preserve merged cells as rectangular data (repeat spanning values), nested tables not duplicated in parent. Include accessible labels/caption, row and column counts, truncation/size warnings. Local capture cap 100,000 cells is a documented safety bound, not a paid limit. No daily/export quota, free CSV/TSV/JSON/Markdown and clipboard with all captured rows.
- Preview with column include/exclude, row text filter, trim whitespace, drop empty rows, optional exact-row dedupe, transpose, header toggle; original data preserved for reversible transforms. Header names in JSON must be unique and safe from prototype pollution. Safe CSV escaping, Unicode BOM, safe formulas (prefix leading =,+,-,@ and control/whitespace variants), TSV escaping and Markdown pipes/newlines. Preview capped with explicit full-export row count.
- Append later captures manually to a current dataset with equal-width schema checks, making page-by-page capture user-controlled. Persist captures and recovery locally through chrome.storage.local; workspace navigation does not lose data. Import/export JSON backups, validate content/limits, local deletion. No server, no telemetry, no remote code or web requests.
- Free export/cleanup unlimited within memory bound; Pro planned $19 lifetime unlocks saved transform recipes and multi-table batch CSV export. Free tier supports 3 recipes; paid key unlocks more plus batch. Export one's own data never held hostage. Clearly show checkout pending until configured.
- K05-style offline ECDSA P-256: C01 prefix, c01 product, plan lifetime/monthly, order, issued, expires, strict length/fields and wrong-product/expired/tamper rejection; private signing material in ignored .secrets only. Manual Paddle fulfillment after dashboard-verification, no Paddle secret/backend in extension. Pending sales noted in UI/docs, no fabricated checkout.
- New visual direction: spreadsheet workshop with white table canvas, #EAF2F2 outer area, deep teal #176B65 primary, slate #24384B text, muted blue #536B7A, amber #9A5C09 warning. Segoe UI body, fixed numerical columns. Left compact capture/cleanup rail and expansive table with real column selection. Narrow stacks rail above table, page no horizontal overflow (table itself scrolls). Semantic forms, visible focus, live status, no innerHTML from page.
