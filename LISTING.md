# Chrome Web Store listing draft

Name: GridHarbor — local table workbench
Summary (under 132 characters): Capture visible tables locally. Clean, select columns and export CSV, TSV, JSON or Markdown without an account.
Category: Developer Tools. Language: English. Version: 0.1.0.

Turn visible web tables into useful files on your device.

GridHarbor keeps original captures while you trim spaces, remove duplicate or empty rows, filter text, choose columns and transpose rows. Preview several captured tables. Append compatible captures into a new table while preserving the sources. Save a local JSON backup and recover your workspace later.

Free includes CSV, TSV, JSON and Markdown exports, clipboard, cleanup and three saved recipes. Individual exports have no daily quota or paid row cap. A shared 100,000-cell workspace bound protects memory and storage; preview shows up to 101 rows and exports include every matching captured row. Very long cells are limited to 10,000 characters.

Works with rendered HTML tables, accessible ARIA grids and explicit list CSS selectors. It does not load unseen rows, crawl pages, automate pagination or read cross-origin frames. Forms, hidden content and contact-linked or email-containing tables are excluded. Use only content you are entitled to process.

Captured text stays in local browser storage. No account, telemetry, application server, paid API or remote code. Back up important work before deleting the extension or profile.

Optional Pro: more saved recipes and batch CSV, planned $19 lifetime. Purchases are not available yet. Product-specific signed license keys verify offline. Free exports remain available without a key.

Independent MIT-licensed fork of Copytables, with attribution retained. Original branding and interface. Source and licensing details are included in the package.
